# 🦠 COVID-19 Global Data Dashboard

## 1. Project Title / Headline

**📊 Global COVID-19 Analytics Dashboard**
An interactive, data-driven dashboard designed to analyze the impact of COVID-19 across countries. It provides a comprehensive overview of cases, deaths, testing, vaccinations, and demographics—empowering policymakers, researchers, and analysts to derive meaningful insights.

---

## 2. Short Description / Purpose

The **COVID-19 Dashboard** is a visualization tool built to track and analyze the global pandemic from 2020 to 2022.
It highlights country-level comparisons, demographic impacts, and vaccination progress using an intuitive interface.

This project demonstrates **end-to-end data handling**—from cleaning raw data to delivering actionable insights in an interactive dashboard.

---

## 3. Tech Stack

The dashboard was built using the following tools and technologies:<br>
• 📊 **Power BI Desktop** – Dashboard creation and visualization. <br>
• 🐍 **Python (Pandas, NumPy, Matplotlib, Seaborn)** – Data preprocessing, cleaning, and exploratory analysis. <br>
• 📂 **Power Query** – Data transformation inside Power BI. <br>
• 🧠 **DAX (Data Analysis Expressions)** – Custom KPIs and measures. <br>
• 📁 **File Format** – `.pbix` (Power BI), `.csv` (dataset), `.png` (dashboard preview).

---

## 4. Data Source

**Source:** [Kaggle – COVID-19 Dataset](https://www.kaggle.com/datasets)

The dataset includes:

* Daily cases, deaths, and testing data.
* Vaccination progress (partially & fully vaccinated).
* Country-level demographics (population, median age, GDP, healthcare factors).
* Government response indicators (stringency index).

---

## 5. Features / Highlights

### • Problem Statement

COVID-19 data is vast and complex, making it difficult to quickly identify patterns in cases, testing, vaccinations, and demographics.

### • Goal of the Dashboard

To deliver an **interactive analytics tool** that:

* Tracks **global & country-level COVID-19 trends**.
* Compares demographic factors (age, poverty, healthcare capacity).
* Highlights vaccination rollout progress.
* Provides insights into healthcare strain (hospital & ICU patients).

### • Walkthrough of Key Visuals

* **KPI Cards (Top Right):** Total Population (51B), Vaccinated (3B), Fully Vaccinated (2B), Total Vaccinations (4B).
* **Country-wise Table:** Cases, Deaths, Testing, Hospital/ICU patients.
* **Time Filters:** Year (2020–2022) + Monthly navigation.
* **Global Map:** Geographic distribution of COVID-19 spread.
* **Charts (Bottom Panel):**

  * Positive rate by location
  * Median age by location
  * Aged 65+ population distribution

### • Business Impact & Insights

* **Public Health Decisions:** Governments can track healthcare strain.
* **Vaccination Strategy:** Identify regions with low vaccine coverage.
* **Demographic Insights:** Older populations show higher vulnerability.
* **Global Comparison:** Understand how countries responded differently.
